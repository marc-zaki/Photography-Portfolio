# Image Assets Guide

To customize this portfolio website with your own photography, drop your images into this `assets/` folder and name them exactly as shown below:

## Hero Section
- `hero.jpg` - Full-screen background image.

## About Me Section
- `about.jpg` - A high-quality profile picture or portrait of yourself.

## Portfolio Categories

### Portraits
- `portrait_1.jpg`
- `portrait_2.jpg`
- `portrait_3.jpg`

### General Photography
- `general-photography_1.jpg`
- `general-photography_2.jpg`
- `general-photography_3.jpg`

### Events
- `event_1.jpg`
- `event_2.jpg`
- `event_3.jpg`
